# Яндекс Карты: режим подключения (3 ноября 2026)

В проект добавлен альтернативный картографический режим через **официальный JavaScript API Яндекс Карт 2.1**. Старые тайлы OSM не загружаются, чтобы не показывать ошибку 403. Четыре точки Псыжа, адреса, описания и фотографии не удалены.

## Запуск

1. Получите **ключ JavaScript API Яндекс Карт** в кабинете разработчика: https://developer.tech.yandex.ru/ (актуальный интерфейс см. https://yandex.ru/maps-api/).
2. Разместите сайт на обычном HTTPS-домене, для которого разрешено использование ключа. Для файла `file://` API может отвергать запросы из-за отсутствия корректного HTTP Referer.
3. Откройте страницу: в области карты появится поле «Ключ JavaScript API Яндекс Карт». Вставьте ключ и нажмите «Подключить Яндекс Карты».
4. После успешной загрузки карты нажмите «Проверить адреса автоматически».

## Ограничения и проверки

- Поиск использует `ymaps.geocode` и выводит результат **только на Яндекс Картах**. Результаты не пишутся в `points.js`, `localStorage`, JSON-экспорт и GitHub.
- Метка появляется при однозначном ответе с `precision=exact`, совпадением населённого пункта «Псыж», названия улицы и полного номера здания. Это **не подтверждает попадание в контур здания** — такой проверки в данном режиме нет.
- В настоящее время 0/4 меток подтверждено реальными ответами. Режим не проходил полноценный тест с действительным ключом и опубликованным HTTPS-сайтом; готовность не заявляется.
- Ключ вводится посетителем вручную, используется в URL загрузки API и виден клиентскому браузеру и Яндексу — **это не серверный секрет**. Ограничивайте ключ настройками кабинета и доменом. Не публикуйте приватные ключи в GitHub.
- Бесплатное использование регулируется актуальными условиями Яндекса: https://yandex.ru/dev/commercial/doc/ru/ и https://yandex.ru/legal/maps_api/ru. Для публичных бесплатных проектов могут действовать бесплатные условия и лимиты; для закрытых или платных сценариев — иные условия. Нельзя хранить геокодированные координаты в своей базе на бесплатных условиях.
- Для постоянных меток без повторного геокодирования требуются координаты, полученные из независимого разрешённого источника, или соответствующая коммерческая лицензия Яндекса.

## Актуальная интеграция и архивы

Параллельные изменения объединены с интеграцией, описанной в [YANDEX-SETUP.md](YANDEX-SETUP.md). Поле ключа находится в боковой панели. Используется один официальный SDK Яндекс и строгая проверка exact/house с полным номером дома. Старый код прямых тайлов OSM удалён.

Архивы kimbo-map.zip и kimbo-site.zip обновлены вместе с исходниками и включают config.js, yandex-map.js и geocoder.js. Это подготовка подключения, а не подтверждение рабочей подложки. Действующий ключ и реальные четыре адреса всё ещё не проверены.
