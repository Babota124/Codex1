## Получить ключ

1. Войти в кабинет разработчика Яндекс: https://developer.tech.yandex.ru/ .
2. Выбрать подключение «JavaScript API и HTTP Геокодер» (название продукта в кабинете может меняться). Нужен ключ для JavaScript API, включая прямое геокодирование через `ymaps.geocode`. Ключ от MapKit, Static API или другого продукта не подходит.
3. Выбрать подходящую лицензию и квоту. До использования проверить актуальные условия в кабинете и по официальным ссылкам ниже. Не оформлять платный тариф автоматически.
4. Указать ограничения по HTTP Referer/доменам сайта. Для GitHub Pages это babota124.github.io; фактический формат маски и поддержка localhost задаются кабинетом. Для локальной проверки добавить разрешённый тестовый адрес, если кабинет поддерживает его. Не оставлять публичный ключ неограниченным после публикации.
5. Дождаться активации ключа и ограничений. Браузерный ключ виден в запросах — это нормально для JavaScript API, но ограничения домена и квоты обязательны для защиты от чужого использования.

## Подключить проект

Открытие двойным щелчком (file://) больше не используется: оно не даёт нормального доменного Referer. Запустить HTTP в папке kimbo-map:

    python3 -m http.server 8000

Открыть http://localhost:8000 с разрешённым для ключа адресом. Либо разместить проект на HTTPS-хостинге. Ввести ключ в поле «Ключ Яндекс JavaScript API», нажать «Подключить Яндекс Карты», затем «Проверить адреса автоматически». Через интерфейс ключ не записывается ни в GitHub, ни в localStorage.

Для общего сайта можно указать публичный браузерный ключ в config.js → yandexApiKey. Публиковать только после настройки ограничений домена; серверные секреты туда не помещать. Адрес SDK: https://api-maps.yandex.ru/2.1/ . Подложка, масштабирование, атрибуция и метки обслуживаются официальным SDK — прямых запросов к OSM или чужим тайловым URL нет.

## Проверка точного адреса

Используется `ymaps.geocode` с полным адресом. Нужны precision=exact, kind=house и точные компоненты: Псыж, улица, номер с буквой и дробью. Несколько разных совпадений и неточные результаты отклоняются. Это точный адресный ответ Яндекс, но не геодезическая съёмка и не независимая проверка физического контура здания. Для окончательного отчёта надо визуально сверить метки с номерами зданий на карте.

Предварительная пара Madu не подставляется. При точном ответе показывается расстояние от ответа до предварительной пары; близость не объявляется доказательством совпадения здания.

## Лицензия и ограничения

Официальные источники:

- https://yandex.ru/maps-api/products/js-api
- https://yandex.ru/maps-api/docs/js-api/
- https://yandex.ru/legal/maps_api/
- кабинет разработчика с текущими квотами и тарифами.

Бесплатное использование зависит от условий продукта, доступности сайта посетителям, цели использования и лимитов. Коммерческий характер Kimbo сам по себе не определяет допустимый тариф: нужно проверить условия конкретного проекта. Закрытый внутренний сайт, хранение/изменение/экспорт результатов геокодирования, использование данных отдельно от карты и превышение квот могут требовать другой лицензии или оплаты. Не считать бесплатный лимит или старую опубликованную цифру гарантией: актуальные квоты и цены в этой среде не подтверждены, официальные страницы блокируются прокси.

Проект по умолчанию использует результаты геокодера Яндекс только в оперативной памяти текущей страницы и на карте Яндекс. Они исключаются из localStorage и JSON-экспорта. После перезагрузки их нужно запросить снова. Исходные пользовательские адреса, комментарии и фотографии по-прежнему сохраняются. Для постоянного хранения геокодированных координат сначала нужна соответствующая лицензия; возможность не включена молча. Логотипы, атрибуция и ссылки SDK не скрываются.

При неверном ключе, запрете Referer, неподходящем продукте, исчерпанной квоте или сетевой ошибке SDK/геокодер могут отказать. Никакие случайные прокси, подмена Referer или альтернативные неофициальные тайловые адреса не используются.

## Другие сервисы

2ГИС MapGL — официальная альтернатива, тоже требует ключа, проверки тарифа и отдельного доступного адресного API. Она не выбрана, чтобы не добавлять второе подключение до проверки Яндекс. OSM стандартные тайлы больше не используются: пользователь получил policy block 403. Смена случайного поддомена или прокси не является исправлением этой ошибки.

## Критерий завершения

С действующим ключом на разрешённом домене: загрузились реальные улицы и здания; четыре адреса дали exact/house и правильные компоненты; метки визуально соответствуют зданиям; карточки и фото работают на компьютере и телефоне. Нужен фактический скриншот с подложкой и метками, а не тестовая имитация. До этого карта НЕ объявляется готовой.
