# Статический хостинг

Проект остаётся в папке kimbo-map того же репозитория. Для официального Яндекс SDK нужен HTTP/HTTPS-сайт и ключ с разрешённым доменом; file:// не подходит. Инструкция: YANDEX-SETUP.md.

GitHub Pages: при наличии прав и поддержки на тарифе — Settings → Pages → Deploy from a branch → main → /(root). Ожидаемый адрес https://babota124.github.io/Codex1/kimbo-map/ не является подтверждённой рабочей публикацией. Не заменять настройки, если Pages уже обслуживает другой проект.

Netlify Drop (https://app.netlify.com/drop) и Cloudflare Pages Direct Upload (https://developers.cloudflare.com/pages/get-started/direct-upload/) технически подходят для статического пакета. Актуальные бесплатные квоты и условия из среды не подтверждены. Публикация на сторонних сервисах не выполнялась и требует разрешения пользователя и доступа к аккаунту.

kimbo-site.zip содержит index.html в корне: распаковать в папку и загрузить её как корень сайта либо загрузить ZIP, если выбранный хостинг поддерживает такой формат. Добавить полученный домен в ограничения ключа Яндекс. В config.js можно поместить только публичный браузерный ключ, не серверные секреты.

Постоянная публикация результатов геокодирования по умолчанию отключена из-за лицензионных ограничений. Адреса, описания и фото редактируются независимо. Для готовности нужны действующий ключ, реальные улицы, четыре точных ответа геокодера и визуальная сверка меток с домами на компьютере и телефоне.
