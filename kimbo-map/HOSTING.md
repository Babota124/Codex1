# Публикация без GitHub Pages

Проект технически совместим с обычным статическим хостингом: HTML, CSS, JavaScript, относительные пути, нет сборки, сервера приложения, токенов и секретов. Внешние запросы к OSM выполняются браузером посетителя.

## Netlify Drop

Обычно доступна бесплатная ручная публикация статической папки: https://app.netlify.com/drop . Распаковать kimbo-site.zip и загрузить содержимое папки kimbo-map, в корне которой лежит index.html. Для постоянного управления сайтом может потребоваться аккаунт. После публикации проверить адрес, кнопку автоматической проверки и загрузку тайлов.

## Cloudflare Pages — Direct Upload

Обычно есть бесплатный вариант статических сайтов с загрузкой файлов через панель Cloudflare: Workers & Pages → Create → Pages → Direct Upload. Загрузить содержимое kimbo-site.zip с index.html в корне сайта. Аккаунт Cloudflare необходим. Ссылка на документацию: https://developers.cloudflare.com/pages/get-started/direct-upload/ .

Актуальные тарифы, лимиты и доступность в регионе из среды не подтверждены: официальные сайты блокируются прокси. Подписка или оплата не оформлялись. На сторонние сервисы ничего не загружено. Для публикации исполнителем нужны разрешение пользователя и доступ к выбранному аккаунту через поддерживаемое подключение. Передавать пароли в чат не нужно.

## Общие данные и результат автопроверки

Браузерная автопроверка сохраняет координаты в localStorage только у текущего посетителя. Чтобы другие посетители сразу увидели подтверждённые метки без повторных запросов, экспортировать JSON после проверки и заменить им массив в points.js (сохранив `window.KIMBO_POINTS =` и завершающую `;`), затем обновить сайт. Можно передать экспорт исполнителю для внесения. Это передача автоматически найденных данных, не ручная расстановка меток.

При загрузке с file:// браузер может ограничить CORS и localStorage. Надёжный вариант — HTTP через `python3 -m http.server 8000` или опубликованный HTTPS-сайт. В пакет не включены тестовые координаты и подложки; реальная карта загружается с tile.openstreetmap.org. Наличие бесплатного хостинга не гарантирует полноту адресных данных OSM.
