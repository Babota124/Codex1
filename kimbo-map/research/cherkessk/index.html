Черкесск · пакетный поиск организаций

Исследование, не опубликованные точки Kimbo. Рабочая карта Псыжа не изменяется. Поиск требует действующего ключа Яндекс JavaScript API с доступом к поиску организаций. Адреса отправляются Яндексу.

Открыть через HTTP/HTTPS. Ключ можно взять из настройки основного проекта: он не записывается на диск.

Исходная записьРезультаты официального поиска (только в сессии)

Результаты API не записываются в localStorage, JSON или GitHub. Это намеренное ограничение до проверки лицензии на сохранение данных. Все найденные филиалы остаются кандидатами; наличие Kimbo в каждом не предполагается.
