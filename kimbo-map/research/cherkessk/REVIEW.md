## Автоматизация следующего прохода

index.html в этой папке — отдельный пакетный исследовательский инструмент, не раздел рабочей карты. Он берёт все названия и адреса из candidates.json и ищет их через официальный Яндекс JS API `SearchControl`, provider `yandex#search`. Включён поиск по вариантам названий и каждому известному адресу филиала. Названия/адреса ответов, кандидаты и координаты живут только в памяти страницы и показываются на Яндекс Картах. Полнота выдачи не обещается; достижение лимита 20 результатов явно отмечается. Сети требуют отдельного подтверждения присутствия Kimbo в филиалах.

Реальный поиск из среды не прошёл из-за сетевого ограничения и отсутствия ключа; код инструмента проверяется отдельно и это не считается проверкой реальных заведений. Владелец не должен искать каждую точку вручную: один запуск обрабатывает всю партию. До подтверждения лицензии не включены выгрузка координат или сохранение результатов API на диск. Ссылка организации показывается только если официальный ответ действительно содержит допустимую ссылку на карточку; URL не сочиняется из названия.
