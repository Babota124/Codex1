# Исследование кандидатов Черкесска

Это отдельные черновики. Они не импортируются в рабочий points.js и не публикуются как точки присутствия Kimbo.

- candidates.json — 12 исходных записей, адресные подсказки и автоматические запросы.
- identified.json — конкретные ссылки из исходного материала; сейчас одна For Chef, без непроверенных координат.
- branch-hints.json — варианты филиалов из исходного файла, не подтверждённые объекты.
- ready-for-map.json — только записи, готовые для нанесения; сейчас пуст.
- REVIEW.md — результаты, происхождение сведений, ограничения и два смысловых вопроса о филиалах.

## Пакетный поиск

Из папки kimbo-map запустить `python3 -m http.server 8000`, открыть http://localhost:8000/research/cherkessk/ . На опубликованном сайте путь аналогичный, но сторонняя публикация не выполнялась. Ввести действующий браузерный ключ Яндекс JS API с доступом к поиску организаций, нажать «Обработать всю партию». Учитываются варианты названий и известные адреса филиалов. Можно остановить после текущего запроса. Ключ не сохраняется, не печатается и не отправляется куда-либо кроме официального SDK.

Требуется доступ к Яндекс и разрешённый HTTP(S)-домен для ключа. Условия продукта/квоты и право использовать поиск организаций нужно проверить в кабинете. Внедрение не означает, что любой ключ JS API автоматически включает нужный доступ.

Результаты только в памяти страницы. Нельзя принимать найденный поисковый результат за подтверждение Kimbo или точности здания. Имя и адрес оцениваются консервативно; филиалы помечаются отдельно. Найденная карточка может иметь другое написание: сомнительные совпадения не становятся готовыми точками. Поисковая выдача не гарантирует полноту сети.

По умолчанию нет экспорта данных/координат API: лицензия на постоянное хранение не подтверждена. Разрешённые координаты можно добавить в ready-for-map.json только с явным coordinateProvenance (источник и основание права сохранять), точным филиалом, проверенной карточкой и подтверждением Kimbo для филиала. Не извлекать скрытые координаты из HTML/тайлов и не выдавать центр улицы за адрес здания.

Чтобы добавить будущую партию: отдельный JSON со структурой items (id, name, city, aliases, addressHints, chain, queries), затем использовать тот же механизм пакетного поиска. Существующая карта и четыре места Псыжа от этого не меняются.

Проверки кода без сетевых запросов: `node test.cjs`. Тестовые данные в test.cjs не являются заведениями для публикации.
