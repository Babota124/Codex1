# Kimbo · аул Псыж

Четыре реальные записи по данным пользователя: Smoker, «Кунжут», офис организации, Madu. Вымышленные исходные точки удалены. **Координаты зданий пока не подтверждены: все четыре записи доступны в списке и карточках, но без меток.** См. COORDINATES.md.

## Открыть

Скачайте kimbo-map.zip, распакуйте и откройте index.html. Если браузер ограничивает локальные страницы, в папке проекта запустите:

    python3 -m http.server 8000

Затем откройте http://localhost:8000. Для реальной подложки с улицами и зданиями необходим доступ к tile.openstreetmap.org. В облачной среде он пока блокируется с HTTP 403; подложка не проверена.

## Точки и фотографии

Нажмите запись в списке: откроется адрес, категория и описание присутствия Kimbo. «Изменить» позволяет добавить несколько ваших фотографий и проверенные координаты. Пустые координаты сохраняют запись без метки. Категории «Офис» и «Супермаркет + кофейня» поддерживаются в форме, фильтре и JSON.

Данные для исходной публикации находятся в points.js. lat — широта, lng — долгота. Не указывайте приблизительные координаты как точные. Фотографии: массив photos с путями вида "photos/entrance.jpg", либо загрузка через форму. Фотографии самостоятельно не ищутся.

Изменения через интерфейс хранятся в браузере: «Экспорт JSON» для резервной копии и передачи, «Импорт JSON» для загрузки списка. Фотографии из формы включаются в экспорт. Для большого объёма храните фотографии в photos/. Для общей публикации замените массив в points.js экспортированными данными, сохранив `window.KIMBO_POINTS =` и `;`.

Новая версия использует отдельный ключ localStorage kimbo-psyz-v2: старые демоточки больше не подменяют реальные исходные записи. Старое хранилище не удалено, чтобы сохранить возможные пользовательские изменения. «Исходные точки Псыжа» возвращает четыре исходные реальные записи после подтверждения.

## Управление и экспорт

Перемещение мышью/пальцем, масштаб колесом, кнопками или жестом двух пальцев. На клавиатуре: стрелки, +/− при фокусе на карте. Поиск и фильтр совместимы. «Печать / PDF» сохраняет текущий вид средствами браузера; до отправки дистрибьютору нужны проверенные координаты и загруженная подложка.

Архив и скриншоты обновлены для текущих записей. Скриншоты без улиц и меток фиксируют техническое ограничение, а не законченный результат. Серверного хранения и синхронизации посетителей нет. Автопроверка адресов описана ниже.

## Автоматическая проверка адресов в обычном браузере

Нажмите «Проверить адреса автоматически». Приложение сначала запрашивает адресные контуры зданий OSM в административной границе Псыжа через Overpass; для отсутствующих совпадений выполняет поиск полного адреса, затем названия с адресом через Nominatim (не чаще одного запроса в 1,2 секунды).

Для метки нужны точные улица, номер с буквой/дробью, населённый пункт и полигон здания. Центр улицы, населённого пункта, отдельная неподтверждённая POI и несколько совпадений отклоняются. Координата рассчитывается внутри подходящего адресного контура; это проверка по открытым данным, а не геодезическая съёмка или независимое подтверждение присутствия Kimbo. Последнее предоставлено пользователем.

Предварительные координаты Madu 44.218198, 42.017297 сохраняются отдельно и не отображаются точной меткой. Проверка определяет, лежат ли они внутри адресного контура. При несовпадении используется только найденный точный адрес здания, а расхождение явно указывается в карточке.

Результаты, время проверки и ссылка на OSM сохраняются в карточках, localStorage и экспорте JSON. Неподтверждённые записи остаются без меток с причиной. Фото не отправляются геокодерам. Геокодирование запускается пользователем, не при каждом открытии сайта. Полнота адресов OSM не гарантирована: при отсутствии здания в открытых данных автоматическая точная метка невозможна.

Обычный браузер с доступом к сервисам может выполнить запросы независимо от прокси среды разработки. Нужны доступ к overpass-api.de, nominatim.openstreetmap.org и tile.openstreetmap.org и поддержка CORS этими сервисами. При ограничениях file:// используйте HTTP/HTTPS. Технические альтернативы публикации описаны в HOSTING.md; сторонняя публикация не выполнялась.

Проверки реализации выполнены с синтетическими ответами источников: точные адреса дают метки, неоднозначные адреса и похожие номера отклоняются, проверяется попадание Madu в контур, сохранение и мобильный экран. Это не подтверждение реальных координат. Скриншоты созданы без подмены реальной картографической подложки.
