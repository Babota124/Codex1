# Kimbo Map · Псыж · переход на Яндекс

Четыре реальные точки и их описания сохранены: кафе Smoker (Шоссейная, 63А), «Кунжут» (Шоссейная, 53А), «Газ-Вода» (Шоссейная, 27А), супермаркет + кофейня Madu (Победы, 4Б/1). Фото можно добавлять в карточках.

**Рабочая карта ещё не подтверждена. Нужен действующий ключ Яндекс JavaScript API и геокодера.** Стандартные тайлы OpenStreetMap, Nominatim и Overpass больше не используются: пользователь получил блокировку OSM tile usage policy.

## Запуск

Распаковать kimbo-map.zip. В папке с index.html:

    python3 -m http.server 8000

Открыть http://localhost:8000. Ключ должен разрешать фактический HTTP/HTTPS-адрес страницы. Открытие через file:// не поддерживается для подключения SDK.

Ввести браузерный ключ Яндекс → «Подключить Яндекс Карты» → «Проверить адреса автоматически». Для опубликованного сайта ключ можно задать в config.js после настройки ограничений домена.

Подробное получение ключа, условия лицензии и критерии проверки: **YANDEX-SETUP.md**. Никакая подписка не оформлялась. Сторонний хостинг не использовался.

## Данные

points.js — исходные пользовательские названия, адреса, категории, описания и фото. photos — массив путей к своим изображениям или фото из формы. Интерфейс поддерживает добавление и редактирование, импорт/экспорт JSON. Пользовательские изменения сохраняются в браузере; экспорт нужен для резервной копии. Исходные четыре записи восстанавливаются кнопкой «Исходные точки Псыжа».

Результаты Яндекс геокодера живут только до перезагрузки страницы: автоматическое постоянное хранение/экспорт отключены до проверки лицензии. Редактирование записи с временными координатами не записывает их в постоянное хранилище; после сохранения её можно проверить снова. Предварительная пара Madu не используется как точная метка.

## Публикация и состояние проверки

kimbo-site.zip — только файлы сайта с index.html в корне. Размещение на GitHub Pages или другом статическом хостинге возможно технически; нужен ключ, разрешающий домен, и подходящая лицензия. Файлы сторонним хостингам не отправлялись. HOSTING.md содержит варианты, но их текущие тарифы не подтверждены.

Проверки с тестовыми ответами подтверждают поведение кода, а не настоящую загрузку карты и не реальные координаты. Скриншоты показывают текущее состояние до подключения ключа. Улицы и четыре метки пока не проверены.
