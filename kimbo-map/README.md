# Kimbo · Черкесск

Статический прототип: четыре вымышленные демонстрационные точки. Это не сведения о фактическом присутствии Kimbo. Используется реальная картографическая подложка OpenStreetMap, не рисунок города. Для её загрузки необходим интернет и доступ к tile.openstreetmap.org. Библиотеки, сборка, ключи API и сервер приложения не нужны.

## Открытие

Распакуйте архив и откройте index.html в современном браузере. Если браузер ограничивает локальные страницы или сохранение данных, из этой папки выполните:

    python3 -m http.server 8000

Откройте http://localhost:8000. На телефоне можно разместить всю папку на обычном статическом HTTPS-хостинге. На публичной странице данные посетителей не синхронизируются: импортируйте утверждённый список в points.js перед публикацией.

## Работа с точками

- Нажмите «Добавить место»: название, категория, адрес, комментарий и несколько ваших фотографий.
- Координаты вводятся только после проверки адреса. Пустые координаты означают «требует уточнения»: запись видна в списке, но метка не ставится. Автоматического геокодирования в этой версии нет.
- Для предоставленного пользователем списка адресов следующий этап — проверить координаты через доступный картографический сервис. Неоднозначные адреса нужно уточнить у пользователя. Новые заведения и фотографии самостоятельно не ищутся.
- В карточке есть «Изменить» и «Удалить». Новые фотографии добавляются к существующим. Удалить отдельные фотографии можно в экспортированном JSON, изменив массив photos, затем импортировать файл.
- «Экспорт JSON» сохраняет весь список, включая загруженные фотографии. «Импорт JSON» заменяет список после подтверждения. При ошибке исходные данные сохраняются.
- Изменения хранятся локально в браузере. Для надёжного хранения и передачи экспортируйте JSON. Большие коллекции фотографий лучше хранить файлами в photos/, с путями в JSON: "photos/entrance.jpg".
- Чтобы обновить исходный список для всех пользователей, замените массив в points.js на содержимое экспортированного JSON, сохранив префикс `window.KIMBO_POINTS =` и завершающую `;`. После обновления ранее сохранённый список в браузере продолжает иметь приоритет: импортируйте новый JSON.

Пример реальной записи (координаты пока не уточнены):

    {"id":"venue-1","name":"Название от пользователя","category":"Кафе","address":"Полный адрес от пользователя","lat":null,"lng":null,"demo":false,"comment":"","photos":["photos/entrance.jpg","photos/interior.jpg"]}

Координаты: числовые lat (широта) и lng (долгота), десятичные градусы. id уникален. Категории: Кофейня, Кафе, Бар, Магазин, Другое. В JSON не допускаются комментарии.

## Карта и экспорт

Перемещение мышью или пальцем; масштаб кнопками, колесом или жестом двух пальцев. С клавиатуры: фокус на карте, стрелки, +/−. Поиск и фильтр работают одновременно. «Печать / PDF» открывает стандартную печать браузера: выберите альбомную ориентацию и сохранение PDF; дождитесь загрузки улиц. Атрибуция OpenStreetMap сохраняется.

Скриншоты desktop/mobile и PDF в поставке показывают состояние интерфейса в среде проверки. Подложка на них отсутствует: облачный прокси запрещает картографический домен (HTTP 403). Они не являются готовой географической презентацией для дистрибьютора. Сделайте финальный PDF через кнопку после открытия с доступом к интернету и внесения реальных точек.

## Яндекс и ограничения

MapKit ориентирован на мобильные приложения и добавляет лишнюю инфраструктуру для этого веб-прототипа. JavaScript API Яндекс Карт обычно требует ключа в кабинете разработчика; актуальные тарифы, квоты и лицензию необходимо проверить на https://yandex.ru/maps-api/ перед интеграцией. Из среды официальный сайт недоступен (прокси HTTP 403), поэтому актуальные условия не подтверждены. Для текущего варианта ключ не требуется.

Стандартные тайлы OpenStreetMap предназначены для умеренного интерактивного использования, без массовой или офлайн-загрузки. Перед широким коммерческим размещением проверьте политику https://operations.osmfoundation.org/policies/tiles/ и при необходимости выберите провайдера. Тайлы отправляют обычные сетевые запросы внешнему сервису. Фотографии не отправляются на сервер приложением.

## Что проверено

В Chromium: четыре метки, открытие карточки, поиск, добавление точки без координат без метки, сохранение после перезагрузки, возврат демоданных, кнопки масштаба, отсутствие горизонтального переполнения при ширине 390px, создание PDF. Загрузка реальных тайлов заблокирована сетью среды и не подтверждена. Серверное хранение, синхронизация и автоматическое геокодирование не реализованы.
