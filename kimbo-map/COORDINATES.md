Прошлый путь через OSM дал 0 из 4 у пользователя, подложка заблокирована по tile usage policy. Он удалён из выполняемого кода. Подготовлена интеграция официального Яндекс API; пользователь сообщил, что ключа пока нет. Получение и условия: YANDEX-SETUP.md.

С действующим ключом каждый адрес проверяется по kind=house, precision=exact, точным компонентам адреса. Это адресная точность сервиса, не независимая проверка полигона. После ответа требуется визуальная сверка зданий. Результаты не сохраняются постоянно до подтверждения лицензии.

Фактический результат на данный момент: реальные координаты четырёх зданий НЕ проверены, рабочая подложка с четырьмя метками НЕ подтверждена. Тестовые ответы не являются географическими доказательствами.
