# Kimbo Map — Черкесск: кандидаты второй партии
Дата: 2026-11-03. Рабочая карта Псыжа не изменена.

## Правила
- Это **список кандидатов**, а не опубликованные метки. Пользователь сообщил, что в этих заведениях есть Kimbo; публичные источники подтверждают лишь существование/адреса объектов, но не наличие Kimbo.
- Не добавлять точки с непроверенными координатами, не придумывать Yandex URL.
- Ссылки на справочники — источник адреса, не равнозначны конкретной карточке Яндекс.
- Вносить каждое заведение/филиал отдельно. Сохранение координат, полученных из Яндекс API, допускается только в рамках подходящей лицензии; независимые координаты и координаты, предоставленные пользователем, отмечать отдельно.
- Дальнейший поиск ссылок и координат — задача агента, не пользователя.

## Практический следующий проход агента
1. Для строк 2, 4, 5, 8 и 12 найти **точные карточки Яндекс** и разрешённый способ определить координаты, подготовить отдельный черновой JSON.
2. По названиям на конкретных улицах уточнить строки 1, 3, 7, 10, 11 без придумывания адресов.
3. По 6 и 9 сверить с пользователем только неоднозначные филиалы, не просить у него переписывать все названия/адреса.
4. **Не менять опубликованный Kimbo Map**, пока нет координат и однозначных соответствий для конкретных точек.
